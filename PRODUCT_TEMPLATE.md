## 1 — Research
- [ ] Save 3–5 reference creatives
- [ ] Identify main competitors
- [ ] Record competitor prices/offers
- [ ] Write why the product may work
- [ ] Identify obvious IP/policy/refund risks
- [ ] Decision: Kill / Backlog / Preparation

## 2 — Supplier & economics
- [ ] Research/contact 2–3 supplier options
- [ ] Unit cost recorded
- [ ] Base US shipping/order recorded
- [ ] Additional-unit shipping recorded
- [ ] Delivery estimate recorded
- [ ] Tracking availability checked
- [ ] Quality evidence/sample checked
- [ ] Capacity checked
- [ ] Refund/replacement terms checked
- [ ] Landed cost calculated
- [ ] Contribution/order calculated
- [ ] Break-even CPA calculated
- [ ] Decision: Kill / Continue

## 5 — Creative preparation
- [ ] Define 3+ angles
- [ ] Define hooks per angle
- [ ] Define bodies/demos
- [ ] Define CTAs
- [ ] Assign creative IDs
- [ ] Prepare assets

## 6 — Organic Test
- [ ] Assign 2–3 accounts
- [ ] Assign device(s)
- [ ] Publishing cadence set
- [ ] Minimum sample/posts set
- [ ] Organic metrics recorded
- [ ] Review product + angle + hook + intent
- [ ] Decision: Kill / Iterate / Organic Scale

## 7 — Organic Scale
- [ ] Expand toward 5–6 accounts if justified
- [ ] Produce new executions of winning concepts
- [ ] Track concept-level performance
- [ ] Select 2–4 paid candidates

## 8 — Paid Test
- [ ] Test budget set
- [ ] Meta tracking verified
- [ ] Spend recorded
- [ ] CTR / CPC recorded
- [ ] ATC / Checkout / Purchases recorded
- [ ] CPA / AOV / Revenue recorded
- [ ] Contribution recorded
- [ ] Compare CPA vs break-even CPA

- [ ] Kill
- [ ] Iterate
- [ ] Scale
