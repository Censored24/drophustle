## 1 — Investigación
- [ ] Guardar 3–5 creativos de referencia
- [ ] Identificar competidores principales
- [ ] Registrar precios y ofertas de competidores
- [ ] Escribir por qué puede funcionar
- [ ] Identificar riesgos de IP, políticas y reembolsos
- [ ] Decisión: Matar / Backlog / Preparación

## 2 — Proveedor y economía
- [ ] Investigar 2–3 proveedores
- [ ] Registrar coste unitario
- [ ] Registrar envío base a EE. UU.
- [ ] Registrar coste por unidad adicional
- [ ] Registrar plazo de entrega
- [ ] Comprobar tracking
- [ ] Comprobar calidad y capacidad
- [ ] Comprobar reembolsos/reposiciones
- [ ] Calcular coste puesto en destino
- [ ] Calcular contribución por pedido
- [ ] Calcular CPA de equilibrio
- [ ] Decisión: Matar / Continuar

## 3 — Oferta
- [ ] Posicionamiento
- [ ] Precio
- [ ] Bundles
- [ ] Garantía
- [ ] Promesa de envío
- [ ] CTA

## 4 — Landing
- [ ] Duplicar plantilla maestra
- [ ] QA móvil
- [ ] QA checkout
- [ ] QA pagos
- [ ] Tracking de Visita
- [ ] Tracking de ATC
- [ ] Tracking de Checkout
- [ ] Tracking de Compra
- [ ] QA de UTMs y atribución

## 5 — Preparación creativa
- [ ] Definir 3+ ángulos
- [ ] Definir hooks por ángulo
- [ ] Definir bodies/demos
- [ ] Definir CTAs
- [ ] Asignar IDs creativos
- [ ] Preparar assets

## 6 — Test Orgánico
- [ ] Asignar 2–3 cuentas
- [ ] Asignar dispositivos
- [ ] Fijar cadencia de publicación
- [ ] Fijar muestra mínima de posts
- [ ] Registrar métricas orgánicas
- [ ] Revisar producto + ángulo + hook + intención
- [ ] Decisión: Matar / Iterar / Escalado Orgánico

## 7 — Escalado Orgánico
- [ ] Expandir hacia 5–6 cuentas si procede
- [ ] Crear nuevas ejecuciones de conceptos ganadores
- [ ] Medir rendimiento por concepto
- [ ] Seleccionar 2–4 candidatos para paid

## 8 — Test de Pago
- [ ] Fijar presupuesto
- [ ] Verificar tracking de Meta
- [ ] Registrar gasto, CTR y CPC
- [ ] Registrar ATC, checkout y compras
- [ ] Registrar CPA, AOV e ingresos
- [ ] Registrar contribución
- [ ] Comparar CPA vs CPA de equilibrio

## Decisión final
- [ ] Matar
- [ ] Iterar
- [ ] Escalar
